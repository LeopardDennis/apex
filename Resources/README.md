# Apex 开发资源包

版本：1

冻结日期：2026-08-19

本目录包含首发版本在编译期随 App 发布的本地增强数据。远程赛事结果仍由 Jolpica 与 OpenF1 提供，本地文件只维护中文名称、赛季主题色、赛道展示信息和设计令牌。

## 目录

- `DesignTokens/design-tokens.json`：App 与 Widget 共用的颜色、字号、间距、圆角和布局基准。
- `Seed/2026/teams.json`：2026 车队中文名称和主题色。
- `Seed/2026/drivers.json`：2026 正式车手中文名称、号码、代码和车队映射。
- `Seed/2026/circuits.json`：2026 有效赛历、中文大奖赛名称和赛道资源状态。
- `Tracks/track-asset.schema.json`：归一化赛道坐标格式。
- `Tracks/2026/`：按赛道拆分的轨迹点和弯角编号资源。

## 数据边界

- 2026 车手、车队、赛历和主题色基线来自 Jolpica 与 OpenF1，并记录源地址和核对日期。
- 赛道几何来源记录在每个资源文件中；只保存绘制所需的归一化坐标，不保存官方 Logo、照片或字体。
- 中文名称是 Apex 的本地展示映射，不作为实体主键。
- 车队主题色按赛季保存；换赛季不得直接复用旧值。
- 取消的巴林站和沙特阿拉伯站不进入有效赛历资源。
- 马德林与雪邦目前缺少可复用的几何源，资源状态保持 `pendingManual`，发布前必须补齐并验收弯角编号。

## 修改规则

1. 先更新远程源快照，再人工检查中文名称和车队映射。
2. 运行 `Scripts/validate-resources.sh`。
3. 检查赛道缩略图在 iPhone、iPad 和 Widget 尺寸下的弯角标签碰撞。
4. 数据更新与 UI 代码分开提交，方便回溯。
