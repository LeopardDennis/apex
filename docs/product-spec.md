# Apex 产品规格

版本：0.2

状态：iPhone 与 iPad 范围及视觉方向已确认，待进入技术设计

## 1. 产品定位

Apex 是一个适合日常快速浏览的 iPhone 与 iPad 方程式赛车信息应用。它不追求直播替代体验，而是把赛历、赛道、赛果和积分信息做得清晰、漂亮、方便查看。

核心用户是开发者本人，因此首发版优先考虑信息密度、稳定性和离线可读性，不引入账号体系、社交关系或商业化机制。

## 2. 产品目标

- 打开 App 后立即知道下一场比赛和下一环节的当地时间。
- 用清晰的赛道预览理解赛道结构和弯角编号。
- 快速查询过去比赛各环节结果。
- 查看当前车手及车队积分榜，并进入对应详情页。
- 通过 Widget 在桌面直接看到下一场比赛或赛季摘要。
- 在数据服务不可用时继续浏览已经缓存的赛历和赛道信息。

## 3. 非目标

- 不提供实时位置、实时圈速、遥测、车手间隔或比赛控制消息。
- 不提供关注车手、收藏车队或“我的车手”。
- 不申请通知权限，不提供提醒开关。
- 不申请日历权限，不提供加入日历。
- 不提供账户、云同步、订阅、广告或内购。
- 不提供新闻流、短视频、社区、聊天、竞猜或 Fantasy。

## 4. 信息架构

主导航固定为三个 Tab：

1. 首页
2. 赛历
3. 积分榜

设置从首页右上角进入，不占用主导航位置。

主要页面关系：

```text
首页
├── 大奖赛详情
│   ├── 赛道信息
│   └── 环节结果
├── 车手详情
├── 车队详情
└── 设置

赛历
└── 大奖赛详情
    └── 环节结果

积分榜
├── 车手积分榜 → 车手详情
└── 车队积分榜 → 车队详情
```

## 5. 页面规格

### 5.1 首页

必须展示：

- 下一场大奖赛中文名称
- 赛道英文/本地名称
- 轮次和比赛周末日期
- 单色赛道缩略图
- 下一环节名称与设备时区时间
- 距离比赛周末的倒计时
- 当前车手和车队积分榜领先者
- 设置入口

不展示实时比赛排名。

### 5.2 赛历

必须展示：

- 当前赛季
- 下一场比赛的重点卡片
- 后续和过往比赛列表
- 每站轮次、日期、中文大奖赛名称、赛道名称和赛道轮廓
- 即将举行、进行中、已结束三种状态

比赛时间统一按设备时区显示。

### 5.3 大奖赛详情

必须展示：

- 轮次、大奖赛中文名称、赛道名称和日期
- 赛道预览
- 全部弯角编号
- 起终点位置
- 行驶方向
- 维修区位置（拥有可靠素材时显示）
- 赛道长度、弯角数、正赛圈数等基础数据
- 比赛周末所有环节及其时间

赛道线使用单一主题色，不使用分段配色。

### 5.4 环节结果

支持以下环节：

- Practice 1 / 2 / 3
- Sprint Qualifying
- Sprint
- Qualifying
- Race

结果页根据环节显示适用字段，例如名次、车手、车队、圈数、时间/差距、积分、最快圈和状态。首发不显示实时刷新状态。

### 5.5 积分榜

车手积分榜展示：

- 名次
- 车手中文名称
- 三字母代码
- 所属车队中文名称
- 车队主题色
- 积分

车队积分榜展示：

- 名次
- 车队中文名称
- 英文名称
- 官方主题色
- 积分

### 5.6 车手详情

必须展示：

- 中文名称为主标题
- 英文名称和三字母代码为副标题
- 车号和车队中文名称
- 使用所属车队官方主题色
- 赛季排名、积分、获胜和领奖台次数
- 每轮积分图
- 最近比赛结果

不展示收藏或关注按钮。

### 5.7 车队详情

必须展示：

- 中文名称为主标题
- 英文名称为副标题
- 官方主题色
- 赛季排名、积分、获胜和杆位次数
- 两位正式车手的中文名称、代码、号码和积分
- 每轮积分图
- 最近比赛结果

### 5.8 设置

首发设置项：

- 名称语言：中文优先
- 赛事时间：设备时区
- 外观：固定深色
- 当前赛季
- 数据更新时间
- 本地缓存占用与清理入口
- 数据和版权说明

不出现通知、提醒或加入日历选项。

### 5.9 iPad 适配

横屏及宽屏尺寸采用主从分栏结构：

- 左侧为赛历、车手积分榜或车队积分榜等列表。
- 右侧保留所选大奖赛、车手或车队的完整详情。
- 选择左侧项目后只更新右侧详情，不离开当前上下文。
- 分栏比例以约 40% / 60% 为基准，并根据可用宽度自适应。
- 窄尺寸或分屏模式无法容纳两栏时，回落为单栏层级导航。
- 两栏各自保持清晰的信息层级，不直接等比例放大 iPhone 页面。

iPad Widget 支持：

- Extra Large：完整比赛周末日程。
- Large：车手或车队赛季摘要。
- Widget 同样不包含提醒、通知或加入日历操作。

## 6. Widget 规格

首发支持五类内容：

1. 下一场大奖赛倒计时
2. 比赛周末完整日程
3. 车手赛季摘要
4. 车队赛季摘要
5. iPad Extra Large 完整周末日程

规则：

- 中文名称优先。
- 数字和关键信息不得缩小到难以阅读。
- 图片、文字和排名列表不得重叠。
- Widget 只展示数据，不提供提醒或加入日历操作。
- 深色背景，主题色用于重点信息。

## 7. 文案与本地化

- App 首发语言为简体中文。
- 车手和车队中文名作为主要展示名称。
- 英文名称、三字母代码和车号作为辅助信息。
- 大奖赛名称使用中文，赛道名称可同时显示本地/英文名称。
- 内部数据使用稳定 ID，不使用中文名称作为主键。

## 8. 视觉规则

- 固定深色主题。
- 使用 iOS 系统字体，不使用官方 F1 字体。
- 不使用官方 F1 标志作为 App 品牌元素。
- 车手继承所属车队主题色。
- 车队主题色按赛季维护，以官方车队视觉为准。
- 赛道预览采用单色线条，并保证弯角编号在小屏幕仍然可辨认。
- 列表与图表的辅助文字最小可读尺寸不得低于设计验收基准。
- 所有页面需要兼容窄屏 iPhone，禁止关键信息截断或重叠。
- iPad 宽屏优先采用系统化主从分栏，不把 iPhone 页面简单拉伸。
- iPad 分屏和较窄窗口需要自动回落为单栏，禁止横向溢出。

## 9. 离线与异常状态

本地优先保存：

- 当前赛季赛历
- 赛道基础资料和预览图
- 最近一次成功获取的结果和积分榜
- 中文名称映射和主题色

异常状态：

- 网络失败时说明无法更新，并继续展示缓存数据。
- 没有缓存时显示明确的重新加载操作。
- 赛季结束且没有后续比赛时，显示“暂无后续赛程”，并允许查看过往比赛。
- 不将数据错误伪装成“暂无数据”。

## 10. 首发验收标准

- 三个主 Tab 均可正常访问。
- 下一场比赛和所有环节时间正确转换为设备时区。
- 赛道详情能清楚显示所有弯角编号。
- 车手和车队均显示中文名称及正确主题色。
- 已结束环节能打开结果页。
- 车手和车队积分榜能进入对应详情页。
- 无通知、提醒、日历、收藏和实时排名入口。
- 无网络时仍能打开已缓存的赛历和赛道资料。
- Widget 在所有支持尺寸下没有文字、数字与图片重叠。
- iPad 主从分栏可从左侧列表切换右侧详情，并保持选择状态。
- iPad 分屏与单栏回落布局无截断、重叠或横向滚动。
